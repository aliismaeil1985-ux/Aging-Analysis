# Tania Inventory Dashboard

منصة تقارير المخزون وتحليل الأعمار — Inventory Analytics & Aging Dashboard

## النشر (Cloudflare Pages عبر GitHub)

عند رفع أي تعديل إلى GitHub، يبني Cloudflare تلقائياً وينشر خلال دقيقتين.

### إعدادات Cloudflare Pages
- **Build command:** *(فارغ — اتركه فارغاً)*
- **Build output directory:** `/`
- **Root directory:** `/`

### الملفات
- `index.html` — المنصة الكاملة (ملف واحد)
- `_headers` — يمنع تخزين الـ cache (يضمن ظهور التحديثات فوراً)
- `_redirects` — توجيه المسارات
- `robots.txt` — منع الفهرسة
